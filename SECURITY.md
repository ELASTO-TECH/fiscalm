# Securitate

Versiuni acceptate: cea mai recentă versiune 0.x.

Raportați vulnerabilitățile confidențial la **security@fiscalm.ro** sau prin raportarea privată de vulnerabilități de pe GitHub. Nu deschideți issue-uri publice. Includeți versiunea, impactul și pașii de reproducere cu date inventate, fără tokenuri sau parole.

Confirmăm primirea în câteva zile și stabilim împreună pașii de remediere și publicare.

# Security

Supported versions: the latest 0.x release.

Report vulnerabilities privately to **security@fiscalm.ro** or through GitHub private vulnerability reporting. Do not open public issues. Include the version, impact and reproduction steps using synthetic data, without tokens or passwords.

We acknowledge reports within a few days and coordinate remediation and disclosure with the reporter.
